# Media catalogue

Every still and clip in `mockups/shared`, grouped into **families** (near-identical shots, and a clip with the still taken from it).

Rules (checked by `node qa/media.mjs`):

- Within one mockup, each FAMILY may appear in only one place. A family groups near-identical shots, and a clip with the still taken from it.
- A <video> and its own poster count as one place. A lightbox / drawer / modal that enlarges something already on the page is not a second place.
- Soft groups: at most 2 'dumbbells' families and at most 3 'wide' strength-floor views per mockup, never next to each other.
- Use a still or clip only for what its description says. Never caption a member as a coach, and never name a person in a photo.
